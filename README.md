# Naurok+

Розширення для браузера, що працює на naurok.com.ua та vseosvita.ua. Блокує примусовий повноекранний режим, відстеження фокусу та видимості, CSS-розмиття, а також дозволяє копіювати питання тесту одним натисканням. Обхід Наурок, та їх систем визначення списування і т.д

---

## Що робить

- Блокує запити на повний екран і підробляє його стан
- Приховує перемикання вкладок від сторінки
- Пригнічує події втрати фокусу
- Видаляє CSS-розмиття та блокування pointer-events
- Відновлює виділення тексту і прокрутку
- Копіює поточне питання та варіанти відповідей у буфер обміну

Усі функції можна вмикати й вимикати окремо у попапі розширення.

---

## Chrome — Встановлення

> Потрібен Chrome 111 або новіший.

**1. Завантаж**

Перейди до [Releases](../../releases) і завантаж `naurokplus.zip`.

**2. Розпакуй**

Розпакуй архів. Має з'явитись папка `naurokplus` з файлом `manifest.json` всередині.

**3. Відкрий розширення**

Відкрий Chrome і перейди за адресою:
```
chrome://extensions/
```

**4. Увімкни режим розробника**

Переключи **Developer mode** у правому верхньому куті сторінки.

**5. Завантаж розширення**

Натисни **Load unpacked**, потім вибери папку `naurokplus` — ту, що містить `manifest.json`.

Іконка Naurok+ має з'явитись у тулбарі. Якщо ні — натисни на іконку пазла і закріпи розширення.

## Firefox — Встановлення

> Потрібен Firefox 109 або новіший.

Firefox підтримує тимчасове завантаження розширень без підпису. Розширення скидається при закритті браузера в тимчасовому режимі.

**1. Завантаж**

Перейди до [Releases](../../releases) і завантаж `naurokplus-firefox.zip`.

**2. Розпакуй**

Розпакуй архів. Має з'явитись папка `naurokplus-firefox` з файлом `manifest.json` всередині.

**3. Відкрий налагодження**

Відкрий Firefox і перейди за адресою:
```
about:debugging#/runtime/this-firefox
```

**4. Перейди до This Firefox**

Натисни **This Firefox** у лівій боковій панелі.

**5. Завантаж розширення**

Натисни **Load Temporary Add-on…**, відкрий папку `naurokplus-firefox` і вибери файл `manifest.json` — саме файл, не папку.

Іконка Naurok+ має з'явитись у тулбарі.

> **Увага:** Тимчасові розширення видаляються при закритті Firefox. Щоб завантажити знову після перезапуску — повтори з кроку 3.

## Постійне встановлення у Firefox (опціонально)

Якщо хочеш щоб розширення зберігалось після перезапуску без підпису:

1. Відкрий Firefox і перейди до `about:config`
2. Знайди параметр `xpinstall.signatures.required`
3. Встанови значення `false`
4. Перейменуй `naurokplus-firefox.zip` на `naurokplus-firefox.xpi`
5. Відкрий `about:addons` у Firefox
6. Натисни на шестерінку → **Install Add-on From File…**
7. Вибери файл `naurokplus-firefox.xpi`

## Використання

Розширення активується тільки на:
- `naurok.com.ua`
- `vseosvita.ua`

На будь-якому іншому сайті воно не працює.

Натисни іконку **N+** у тулбарі щоб відкрити попап. Кожен перемикач спрацьовує одразу без перезавантаження сторінки.

**Скопіювати питання** — копіює поточне питання та всі варіанти відповідей у буфер обміну у такому форматі:

```
Текст питання

1. Варіант А
2. Варіант Б
3. Варіант В
```

## Перемикачі

| Перемикач | Що робить |
|---|---|
| Блокувати повний екран | Перехоплює запити на fullscreen, підробляє стан |
| Приховувати перемикання вкладок | Утримує `visibilityState` у стані `visible` |
| Пригнічувати втрату фокусу | Блокує події `blur` і `focusout` |
| Блокувати відхід миші | Відкидає `mouseleave`, `mouseout`, `pointerleave` |
| Прибирати CSS-розмиття | Прибирає `filter:blur` і `pointer-events:none` |
| Дозволити виділення тексту | Перевизначає `user-select:none` глобально |
| Розблокувати прокрутку | Видаляє `overflow:hidden` з `html`/`body` |

## Мови

Розширення автоматично визначає мову браузера і перемикається між українською, російською та англійською. Змінити вручну можна у вкладці Налаштування.
